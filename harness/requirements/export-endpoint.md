# Requirement: Export Endpoint

Acceptance criteria are human-authored only. Do not invent, infer, broaden, or fill in acceptance criteria.

## Scope

The `api/experimental/export/` API supports downloading a graph so it can be visualized locally.

## Acceptance Test Criteria

- The API path is `api/experimental/export/`.
- The API enables downloading the graph.
- The downloaded graph can be visualized locally.
- The API can take an identifier.
