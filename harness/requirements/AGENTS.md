Requirements in this folder must be heavily modularized.

Use one narrowly scoped requirement per document. Split broad behavior into smaller requirement documents instead of combining unrelated concerns.

Every requirement document must start with a note that acceptance criteria are human-authored only.

Every requirement document must include acceptance test criteria that were explicitly instructed by a human. Do not invent, infer, broaden, or "fill in" acceptance criteria. If a human has not provided acceptance criteria for a requirement, leave the requirement uncreated or mark it as blocked until the human supplies them.
